## 1. Mục đích tác vụ (Intent)
Khởi tạo cấu trúc dự án React + Vite tại `/Users/tranhaibang/.gemini/antigravity-ide/scratch/genki-sales-portal`. Cài đặt hệ thống Design Tokens nhận diện thương hiệu Genki Fami (`#006964`, `#51BF9D`, Inter, Space Grotesk, JetBrains Mono). Xây dựng `AppContext` với lưu trữ LocalStorage, nạp sẵn bộ Seed Data mẫu hoàn chỉnh cho cả 7 vai trò, các khách hàng, hợp đồng và đề nghị. Xây dựng Header với thanh chuyển đổi vai trò Demo Role Switcher và Sidebar Navigation responsive.

## 2. Bối cảnh & Lý do (Why)
Đây là nền móng của toàn bộ hệ thống portal. Cần một bộ khung UI chuẩn mực, dễ sử dụng, không cần backend phức tạp mà vẫn mô phỏng đầy đủ dữ liệu thực tế để người dùng trải nghiệm tức thì.

## 3. Tiêu chí nghiệm thu (Acceptance Criteria - AC)
- [ ] **AC-1:** Dự án khởi tạo với React 18, Vite, chạy được lệnh `npm run dev` hoặc `npm run build` không lỗi.
- [ ] **AC-2:** File CSS chứa đầy đủ biến màu Genki Fami (`--gf-primary`, `--gf-secondary`, `--gf-accent`, `--gf-tint`, `--gf-ink`) và typography.
- [ ] **AC-3:** `AppContext` cung cấp đầy đủ dữ liệu ban đầu cho 7 vai trò (`STAFF`, `CTV`, `PARTNER`, `MANAGER`, `ACCOUNTING`, `DIRECTOR`, `ADMIN`).
- [ ] **AC-4:** Header hiển thị thông tin người dùng hiện tại, có thanh Demo Role Switcher cho phép bấm chọn vai trò bất kỳ để chuyển đổi tức thì.
- [ ] **AC-5:** Sidebar navigation chứa các mục: Trang chủ (Dashboard), Nhân sự (People), Khách hàng (Customers), Hợp đồng (Contracts), Đề nghị tác nghiệp (Operations), Việc cần làm (My Tasks), Quản trị (Admin) - chỉ hiện khi là Admin. Có badge hiển thị số việc cần xử lý.
