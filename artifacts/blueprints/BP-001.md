## 1. Mục Tiêu & Nguyên Tắc Cốt Lõi

1. **Mục tiêu:** Xây dựng cổng vận hành nội bộ thống nhất (Partner / Staff Operations Portal) dành cho nhân viên, cộng tác viên (CTV), đối tác kinh doanh và ban quản trị Genki Fami.
2. **Khóa ranh giới (Strictly Out of Scope):**
   - KHÔNG quản lý doanh thu, đơn hàng, tồn kho, sản phẩm, commission, P&L, kế toán, CRM pipeline, opportunity.
   - KHÔNG lưu trữ file hợp đồng, ảnh hóa đơn, OCR hóa đơn, e-signature.
   - CHỈ lưu trữ: metadata, trạng thái, quan hệ dữ liệu, Google Drive URLs, link miniapps bên ngoài.
3. **Tiêu chí trải nghiệm người dùng (UX):**
   - Đơn giản, trực quan, không dùng thuật ngữ kỹ thuật (database, schema, payload, RBAC).
   - Thiết kế theo nguyên tắc "Action first, system second".
   - Tối ưu giao diện cho cả Mobile/Tablet (cho CTV/Partner ngoài thị trường) và Desktop (cho Quản lý/Kế toán/Giám đốc).

## 3. Tech Stack & Công Cụ

- **Nền tảng & Build Tool:** React 18 + Vite (SPA nhanh, tối ưu, dễ bảo trì).
- **Ngôn ngữ:** JavaScript / JSX hiện đại (ES Modules).
- **Phong cách thiết kế (Design System):** Genki Fami Brand Identity
  - Màu chủ đạo: `#006964` (Primary Teal), `#51BF9D` (Secondary Mint), `#A71D45` (Accent Magenta), `#D7EDE6` (Tint), `#191919` (Ink).
  - Typography: Inter (Body), Space Grotesk (Headings), JetBrains Mono (Codes, Numbers).
  - CSS: Vanilla CSS theo CSS Variables, Clean Card Layout, Glassmorphism nhẹ, Responsive Grid.
- **Lưu trữ & Dữ liệu:** LocalStorage persistence với cơ chế Seed Data phong phú cho 7 roles và dữ liệu mẫu đa dạng.
- **Kiểm thử & Nghiệm thu:**
  - Automated Unit Tests với Node.js test runner.
  - Cổng nghiệm thu tự động `verify.py` của Skill Lab.
  - Ghi nhật ký tiến trình với `audit_logger.py`.

## 5. Đặc Tả Mô Hình Dữ Liệu & Quy Chuẩn (Data Schema)

### 5.1. Person Schema
- `id`, `fullName`, `phone`, `email`, `dateOfBirth`, `address`, `identityNumber`, `taxNumber`
- `bankName`, `bankAccount`, `bankAccountName`
- `personType`: `EMPLOYEE` | `CTV` | `BUSINESS_PARTNER`
- `role`: `STAFF` | `CTV` | `PARTNER` | `MANAGER` | `ACCOUNTING` | `DIRECTOR` | `ADMIN`
- `managerId`, `region`, `position`, `startDate`, `endDate`, `status` (`ONBOARDING` | `ACTIVE` | `SUSPENDED` | `ENDED`), `driveFolderUrl`

### 5.2. Customer Schema
- `id`, `name`, `customerType`, `region`, `address`, `contactPerson`, `phone`, `email`
- `ownerId` (liên kết Person phụ trách), `createdBy`, `status`, `notes`, `externalSalesAppUrl`

### 5.3. Contract Schema & Template
- `id`, `contractCode` (`CTR-2026-XXXX`), `personId`, `contractType`, `templateId`
- `startDate`, `endDate`, `salary`, `allowance`, `travelAllowance`
- `commissionDescription`, `targetDescription`, `territoryDescription`, `additionalTerms`, `customFields`
- `status`: `DRAFT` → `SUBMITTED` → `DIRECTOR_REVIEW` → `APPROVED` → `ACTIVE` → `EXPIRED` (`REJECTED`, `REVISION_REQUESTED`, `TERMINATED`)
- `driveFolderUrl`, `approvedBy`, `approvedAt`

### 5.4. Unified Request Schema
- `id`, `requestCode` (`TRIP-2026-XXXX`, `ADV-2026-XXXX`, `PAY-2026-XXXX`, `SET-2026-XXXX`, `SAM-2026-XXXX`)
- `requestType`: `BUSINESS_TRIP` | `ADVANCE` | `PAYMENT` | `SETTLEMENT` | `SAMPLE`
- `requesterId`, `managerId`, `status`, `title`, `description`, `amount`
- `customerId`, `parentRequestId`, `rootRequestId`
- `payload`: dữ liệu đặc thù theo từng loại
- `workflowTemplateId`, `workflowInstanceId`, `currentWorkflowStep`, `driveFolderUrl`, `externalAppUrl`
- `timeline`: mảng các sự kiện `[{ actor, action, timestamp, comment }]`

### 5.5. Logic Liên Kết: Trip → Advance → Settlement
```javascript
const difference = actualExpense - advanceAmount;
if (difference > 0) {
  companyReimbursement = difference; // Công ty chi trả bổ sung
  refundToCompany = 0;
} else if (difference < 0) {
  refundToCompany = Math.abs(difference); // Nhân viên hoàn ứng về công ty
  companyReimbursement = 0;
} else {
  // Bằng 0: Quyết toán cân bằng
}
```

## 6. Phân Bổ 5 Gói Chỉ Thị (TIPs)

- **TIP-001:** Khởi tạo dự án Vite React, cài đặt CSS variables Genki Fami, AppContext với cơ chế LocalStorage + Seed Data 7 roles, Global Header, Role Switcher và Sidebar navigation.

- **TIP-003:** Xây dựng Operations Center với 5 Quick Actions, logic liên kết Trip → Advance → Settlement tự động tính chênh lệch, Request Detail với timeline và các nút hành động (Duyệt/Từ chối/Sửa/Thanh toán).
